# Zachitan v5.0.0-beta.2

Release date: 2026-09-13

This release keeps Zachitan's selective-publication contract and closes production correctness issues discovered during live smoke testing.

## Correctness

- Correct Yahoo prior-session close semantics.
- Derive Yahoo session state conservatively when the explicit state is absent.
- Withhold all numeric targets for `RESEARCH_ONLY` and `ABSTAIN`.
- Do not fabricate future exchange dates without an authoritative calendar.
- Capability-normalize Yahoo interval/range combinations before upstream requests.
- Do not label the preceding Coinbase intraday bar as a previous trading-session close.

## Evidence history

- Model evidence history is independent of chart/display range.
- Forecast validation uses a provider-safe `modelCandles` window while the UI receives only `displayCandles`.
- Analysis-cache identity is based on the actual evidence window rather than chart zoom.
- Responses expose model/display row counts and history-limit state.

## Architecture

- The production data handler lives in `lib/market-api-v5.mjs`; `app/api/data/route.js` is a small Next.js adapter.
- Release branding is sourced from the v5 release contract.

## Accuracy status

The 16-case real-market benchmark executed successfully but does not permit a broad accuracy claim. Median ensemble skill versus unchanged price is negative and the joint positive point/probability rate is only 6.25%. Numeric publication therefore remains conditional on local chronological point skill, probability skill, session, integrity and regime gates.
